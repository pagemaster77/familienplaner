# Familienplaner

Web-App für Familie und Planung (Aufgaben mit Punkten, Einkauf, Chat, Termine, Essensplan, Tablet-Kalender).

- `site/` – die App (wird von Netlify veröffentlicht)
- `sql/` – Datenbank-Skripte für Supabase
- `supabase/functions/` – die zwei Hilfsfunktionen (Kalender-Import, Rezept-Import)
- `ANLEITUNG.md` – Einrichtung Schritt für Schritt
